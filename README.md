## About me / 关于我

我的项目围绕机器人控制、强化学习与 AI 应用展开：从人形机器人跑步策略、自主变道决策，到学习工具与多模态交互。

My projects explore robot control, reinforcement learning, and AI applications — from humanoid locomotion and lane-change decisions to learning tools and multimodal interaction.

- **Robotics / 机器人** — G1 人形机器人跑步策略训练与部署。
- **Reinforcement learning / 强化学习** — DQN、PPO 与决策策略评估。
- **AI applications / AI 应用** — 学习工具、情绪感知与交互体验。
